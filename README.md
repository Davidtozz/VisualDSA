**VisualDSA** is a web-based visualization tool designed to help you interact with, analyze, and understand various data
structures and algorithms through step-by-step visual execution.

---

# 🚀 Features

- **Controlled Execution:** Pause, play, and step through sorting algorithms frame-by-frame.
- **Multi-Language Source Code:** View clean, textbook implementations of each algorithm and data structure across
  multiple languages including **C**, **C++**, **Java**, **TypeScript**, and **JavaScript**.

---

# 📊 Supported Visualizations

### 🧩 Data Structures (4)

- Linked Lists
- Stacks
- Binary Search Trees (BST)
- Graphs

### ⚡ Sorting Algorithms (8)

- Bubble Sort
- Selection Sort
- Insertion Sort
- Shell Sort
- Quick Sort
- Merge Sort
- Heapsort
- Radix Sort
- Bogo Sort (Random Sort)

### 🌐 Graph Algorithms (2)

- Breadth-First Search (BFS)
- Depth-First Search (DFS)
